# Contract: application API (`sales_data_analyzer.application`)

Typed Python API used by the terminal adapter now and by the GUI later. It
performs no console I/O. All signatures are keyword-friendly and fully typed.

```python
class SalesSession:
    def __init__(self) -> None: ...
    @property
    def workspaces(self) -> tuple[CompanyWorkspace, ...]: ...
    @property
    def current(self) -> CompanyWorkspace | None: ...
    @property
    def selection(self) -> Selection: ...
    def create_company(self, name: str, sector: str) -> CompanyWorkspace: ...
    def select_company(self, index: int) -> CompanyWorkspace: ...   # 1-based
    def require_current(self) -> CompanyWorkspace: ...
    def set_period(self, start: date, end: date) -> None: ...        # inclusive days
    def clear_period(self) -> None: ...
    def selected_sales(self) -> SalesDataset: ...
    def run_financial_analysis(self) -> AnalysisResult: ...
    def run_product_analysis(self) -> AnalysisResult: ...
    def run_forecast(self, *, horizon: int = 7, test_days: int = 2,
                     missing_days: Literal["reject", "zero"] = "reject",
                     utc_offset: timedelta | None = None) -> ForecastResult: ...
    def data_is_aware(self) -> bool: ...   # True if current sales carry offsets

class CompanyWorkspace:
    def __init__(self, company: Company) -> None: ...
    @property
    def company(self) -> Company: ...
    @property
    def products(self) -> tuple[Product, ...]: ...                  # by ID
    @property
    def sales(self) -> SalesDataset: ...
    def register_product(self, product_id: str, name: str, category: str) -> Product: ...
    def find_product(self, product_id: str) -> Product | None: ...
    def has_sale(self, sale_id: str) -> bool: ...
    def record_sale(self, sale_id: str, date_time: datetime,
                    items: Sequence[ItemInput]) -> Sale: ...
    def import_sales(self, path: str | Path,
                     importer: DataImporter | None = None) -> ImportSummary: ...
```

## Guarantees

- Every method either completes or raises without changing state (a refused
  `create_company` may still advance the level 1 `Company` auto-id counter;
  ids are never reused and have no other effect).
- Money values are `Decimal` in and out; nothing is rounded.
- Exceptions: `TypeError` for wrong argument types, `ApplicationError`
  subclasses for rule violations, domain `ValueError`s and
  `ImportValidationError` propagated unchanged.
- `run_forecast` raises `NoSalesInSelectionError` / `InsufficientHistoryError`
  itself and propagates other forecaster `ValueError`s; the adapter maps them.
- Exception messages contain counts only, never IDs, values or paths.
- No method imports scikit-learn except through `run_forecast`.
